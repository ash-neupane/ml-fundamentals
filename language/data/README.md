# language data

Text corpora used by the language experiments (notebooks/bpe.ipynb, etc.).

## Expected files

- `shortjokes.csv` — Short Jokes dataset (~24 MB, ~230k rows)

## Download

Grab from Kaggle:

- https://www.kaggle.com/datasets/abhinavmoudgil95/short-jokes

Place the resulting `shortjokes.csv` in this directory.
